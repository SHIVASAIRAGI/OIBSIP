
# Nova Smart Calculator

## Project Description
Nova is a modern, responsive calculator built using HTML5,
CSS3 and vanilla JavaScript.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Percentage and remainder
- Decimal number support
- Operator precedence
- Clear and delete buttons
- Keyboard support
- Division-by-zero error handling
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Open the project folder.
2. Open index.html in your web browser.
3. Start calculating.
