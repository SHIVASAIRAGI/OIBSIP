
# DayFlow – Smart To-Do Web Application

DayFlow is a responsive task management application developed for the Oasis Infobyte Web Development Internship.

## Features

- Add, edit and delete tasks
- Mark tasks as completed
- All, Active and Completed filters
- Task priority management
- Due date and time scheduling
- Browser notification reminders
- Repeating alarm tone until stopped
- Individual reminder enable/disable
- Overdue task detection
- Task sorting
- Daily progress tracking
- Local Storage persistence
- Responsive desktop and mobile interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
- Notifications API
- Web Audio API

## How to Run

1. Open the folder in Visual Studio Code.
2. Open index.html with Live Server.
3. Click Enable Notifications.
4. Allow notifications in your browser.
5. Add a task and choose a future date and time.
6. Keep the website open for reminders and alarms.

## Reminder Limitations

Browser reminders operate while the webpage is open. Notifications may also depend on browser permission and operating system settings. The browser's local storage keeps tasks on the same device and browser.
