# Virat Kohli Tribute Page

## About the Project

A responsive and interactive tribute website dedicated to
Indian cricketer Virat Kohli.

The website celebrates his cricket journey, achievements,
career milestones, records and contribution to Indian cricket.

## Features

- Indian cricket-inspired blue theme
- Large hero photograph
- Responsive navigation bar
- About and biography section
- Animated career statistics
- Achievement cards
- Interactive career timeline
- Scroll reveal animations
- Photo gallery with popup viewer
- Back-to-top button
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- index.html
- style.css
- script.js
- README.md
- images/

## Run Locally

Open index.html using the VS Code Live Server extension.
