
# Smart Calculator

## About the Project
Smart Calculator is a responsive browser-based calculator
developed as part of the Oasis Infobyte Web Development
Internship.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Addition, subtraction, multiplication and division
- Decimal number calculations
- Operator precedence
- Clear and delete buttons
- Division-by-zero error handling
- Keyboard support
- Responsive user interface

## How to Run
1. Download or clone this repository.
2. Open the WebDev-L1-Calculator folder.
3. Open index.html in your browser.
